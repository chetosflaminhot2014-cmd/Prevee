# Gato Terror — Minecraft Bedrock

Addon en desarrollo, guardado en esta carpeta para no mezclarlo con la aplicación Prevee.

## Contenido
- `GatoTerrorBP`: entidad invocable `gato:gato_terror`, con 100 de vida, daño 6 y persecución de jugadores.
- `GatoTerrorRP`: definición de cliente, geometría inicial de gato alto con sombrero y controlador de renderizado.
- GitHub Actions prepara un archivo `.mcaddon` descargable.

## Instalar
1. Descarga el artefacto `Gato-Terror-mcaddon` desde la ejecución de GitHub Actions.
2. Abre el `.mcaddon` con Minecraft Bedrock.
3. Activa los dos paquetes en un mundo y prueba `/summon gato:gato_terror`.
