# Prevee 1.0

Primera versión de una plataforma escolar independiente para Android.

## Funciones iniciales
- Inicio y navegación por secciones.
- Materias y tareas de ejemplo.
- Agregar y eliminar tareas guardadas en el dispositivo.
- Calificaciones de demostración.
- Horario de ejemplo.
- Perfil editable guardado localmente.

## Compilar APK
El workflow de GitHub Actions compila automáticamente la app al subir cambios a `main`. También se puede iniciar desde **Actions → Build Android APK → Run workflow**. Cuando termine, abre la ejecución y descarga el artefacto `Prevee-debug-apk`.

Esta es una maqueta funcional de demostración; no está conectada a los sistemas oficiales de ninguna escuela y las calificaciones/horarios incluidos son datos de ejemplo.
